# 相册与灯箱 — 设计决策

## 1. 灯箱序列：游标快照（cursor snapshot），而非实时重定位

**选择：打开灯箱时通过 `POST /api/sequence` 把当前筛选结果固化为服务端快照
（`seq_id` + 有序 id 列表 + 全局 `seq_version`），翻页只在这个冻结列表上移动。**

| | 游标快照（采用） | 实时序列重定位 |
|---|---|---|
| 翻页中新增作品 | 不可见，序列稳定 | 插入当前位置前 → 后续作品全部位移 |
| 翻页中下架作品 | 原位保留墓碑页，双向跳过 | 位置塌陷，左右键可能重复落回同一张 |
| 实现复杂度 | 服务端存快照，客户端纯索引移动 | 每次按键都要重新解析"当前在筛选结果中的位置" |
| 一致性 | 一次会话内绝对一致 | 依赖时序，竞态窗口大 |

**下架行为定义**（`SequenceNavigator`，测试锁定）：
- 下架项**保留槽位**，位置永不位移 → 左右键不会重复跳回同一张；
- 当前停留项被下架 → 显示墓碑页（"该作品已下架"），仍可向前/后离开；
- 离开墓碑后它与其他下架项一样被**双向跳过**，不再回跳；
- 序列两端硬停止，不循环回卷；
- 新打开灯箱（新快照）不再包含已下架项。

## 2. 预加载与标题一致性

每个预加载任务绑定 `(photoId, variantId, token)` 三元组（`PreloadGate`）。
图片字节晚到时先过 `commit()`：token 不是当前值就丢弃并 `revokeObjectURL`，
**旧图永远不会盖住当前标题**。同一张图重新生成变体后 URL 变化（`v1→v2`），
视为新任务。关闭灯箱时 abort 全部在途请求、释放全部 objectURL、焦点还给
触发元素（`opener.focus()`），并注册简单的 Tab 焦点陷阱。

## 3. 缩略图：服务端预生成 vs 按需生成

**选择：上传时预生成为主，按需生成兜底，两者共用同一条管线与同一组限制。**

| | 预生成（上传时） | 按需生成（`/api/variant/<id>/<kind>`） |
|---|---|---|
| 首屏延迟 | 低（直接命中 immutable 缓存） | 首请求触发转换，延迟高 |
| 存储成本 | 全量变体都落盘 | 只存被访问的 |
| 流量突增 | 无感（早已生成） | 转换风暴风险 → 需要并发闸 |
| 适用 | 公开画廊（本系统默认） | 冷数据/长尾尺寸 |

共享约束（`server/variants.py`）：
- **并发**：全局信号量（默认 2），按需路径非阻塞获取，满了返回
  `503 + Retry-After`，客户端退避重试；
- **像素预算**：源图 > 60MP 拒绝（413），单变体 ≤ 2048×2048，
  防解压炸弹；`-strip` 保证 EXIF 不出原图；
- **失败回退**：变体行标记 `failed`，API 返回 503，前端换
  `placeholder.svg`，不会重试风暴。

## 4. 缓存与版本

- 变体 URL 携带版本：`/media/<photo>/<kind>/v<n>.jpg` →
  `Cache-Control: immutable, max-age=1年`；
- 下架/撤销授权 → 变体行 `revoked`，**旧 URL 永久 410**（`no-store`）；
  重新上架生成**新版本号**，旧链接永远不能复活已撤下变体；
- 列表 API：`no-cache` + `ETag(seq_version)`，任何排序/可见性变化
  都会 bump 全局 `seq_version`；
- 历史状态（`history.replaceState`）只存 `{seqId, index}`——
  不含标题、描述、图片 URL 等任何非公开信息；
- 已下载到本地的副本无法召回（HTTP 缓存的固有限制），但链接失效
  保证了"不能重新取得"。

## 5. 权限在服务端执行

- 原图下载 `/api/photos/<id>/original` 每次请求都检查
  `license.allow_download` 与作品状态：403 / 410，UI 隐藏按钮只是提示；
- `/media/.../original/...` 路由不存在（只服务 thumb/medium/large）；
- 授权撤销立即影响所有使用该授权的作品（列表、公开元数据、变体、原图）；
- 同一内容哈希可挂多条不同授权的作品记录，权限各自独立；
- EXIF（含 GPS）只存服务端私有字段，公开元数据端点不含任何 EXIF，
  变体生成时 `-strip` 物理清除。

## 6. 验收覆盖（tests/）

`test_acceptance.py`（14 项，真实 HTTP）：撤销授权、EXIF 位置泄露、
同图不同授权、原图下载权限、变体 URL 过期不复活、序列快照稳定、
分页顺序/版本/乱序回声、网络中断钩子、像素预算、并发饱和 503、
生成失败回退、缓存头、管理接口鉴权。

`test_frontend_logic.mjs`（10 项，Node）：乱序响应丢弃、快照跳过下架项、
墓碑页语义、端点硬停止、预加载身份提交、退避重试、4xx 不重试。
